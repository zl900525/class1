# 匿名聊天室 設計規格

> 本文件整理 `/design` 的設計結果，給做前端時對照用。
> 畫面上「有什麼」和「做什麼」以 `docs/architecture.md` 第 7 節為準；本文件只規定「長什麼樣子」。
> 設計畫布（只有擁有者看得到，要先分享才能給別人看）：https://claude.ai/artifact/KeAPXg2i7wTnAU4u83syUu

---

## 1. 風格

**活潑、塊狀色彩（Neo-brutalism）**：每個區塊都有粗黑框，右下角有沒有模糊的實心黑影，看起來像是蓋在紙上的色塊。顏色鮮豔但種類少，字體粗。

原則：
- 每個可以點的東西都有黑框；主要的東西再加實心影子。
- 鮮豔底色上的文字一律用黑色 `#111111`。深色模式也一樣。
- 圖示一律用線條 SVG（線寬 2.5、圓角端點），不用 emoji 當圖示。只有 6 個表情回應是 emoji。
- 可以點的東西至少 44×44px。

## 2. 設計變數（design tokens）

前端用 CSS 變數實作。深色模式用 `@media (prefers-color-scheme: dark)` 跟著系統切換，不做切換按鈕。

### 2.1 顏色

| 變數 | 用途 | 淺色 | 深色 |
|---|---|---|---|
| `--bg` | 頁面背景 | `#E9E4FF` | `#1A1730` |
| `--surface` | 頂端列、輸入區、卡片、別人的訊息 | `#FFFFFF` | `#2A2547` |
| `--ink` | 主要文字 | `#111111` | `#F4F2FF` |
| `--line` | 框線、實心影子 | `#111111` | `#000000` |
| `--muted` | 時間、進出提示、說明文字 | `#3D3D3D` | `#CFCAEE` |
| `--own` | 自己的訊息 | `#7DF9C2` | `#2BD99A` |
| `--quote` | 引用區底色 | `#EFEAFF` | `#3A3462` |
| `--input` | 輸入框底色 | `#FFFDF2` | `#221E3B` |
| `--disabled` | 不能按的按鈕底色 | `#CFCBDD` | `#4A4566` |
| `--disabled-ink` | 不能按的按鈕文字 | `#555555` | `#BDB8DA` |

**兩種模式共用的強調色**（上面的文字一律用 `#111111`）：

| 變數 | 色碼 | 用在哪裡 |
|---|---|---|
| `--pink` | `#FF5C8A` | 主要按鈕（進入、送出）、「↓ N 則新訊息」、引用區左邊的色條、上傳進度條、短暫提示的影子 |
| `--yellow` | `#FFD93D` | 連線中斷橫幅、自己按過的表情標籤、表情選擇小框、拖曳時的遮罩、圖片檢視的關閉鍵 |
| `--mint` | `#7DF9C2` | 線上人數、線上名單標題 |
| `--online-dot` | `#2BD99A` | 線上名單每個人前面的小圓點 |
| `--error` | `#FF9F7A` | 錯誤提示、⚠ 傳送失敗 |
| `--strip` | `#111111`（文字白色） | 展示模式提示條、日期分隔線、短暫提示 |
| `--link` | `#3A2BD1`（滑鼠移上去 `#1E1480`） | 訊息裡的連結（淺色模式），粗體加 2px 底線 |

> 深色模式的連結顏色還沒設計，建議用 `#B8AEFF`，實作時再確認對比度。

### 2.2 字體

從 Google Fonts 載入：

| 用途 | 字體 | 粗細 |
|---|---|---|
| 一般文字（英數） | Space Grotesk | 500、700 |
| 一般文字（中文）、標題 | Noto Sans TC | 500、700、900 |
| 訊息時間、字數 | Space Mono | 700 |

- 一般文字：`font-family: 'Space Grotesk', 'Noto Sans TC', sans-serif`。英數字用 Space Grotesk，中文會自動改用 Noto Sans TC。
- 標題和按鈕：`'Noto Sans TC'`，粗細 900。

| 文字 | 大小 |
|---|---|
| 進入畫面大標題 | 56px / 900，行高 1.05 |
| 頂端列標題 | 手機 20px、電腦 24px / 900 |
| 訊息內容 | 16px，行高 1.45～1.5 |
| 別人訊息上方的代號 | 13px / 700 |
| 訊息時間 | 11px Space Mono |
| 進出提示、說明文字 | 13px |
| 日期分隔線 | 12px / 700 |

### 2.3 框線、圓角、影子

| 東西 | 框線 | 圓角 | 影子 |
|---|---|---|---|
| 大卡片（進入表單、名單、選單） | 3px | 20px | `6px 6px 0 var(--line)` |
| 訊息泡泡 | 2.5px | 18px，**靠說話者那一側的上角是 4px**（別人的是左上，自己的是右上）；合併顯示的第二則起四角都是 18px | `3px 3px 0` |
| 按鈕、輸入框 | 2.5～3px | 12～14px | 主要按鈕 `3～4px` |
| 表情標籤、人數 | 2px | 999px（膠囊形） | 只有自己按過的才有 `2px 2px 0` |
| 頂端列、輸入區的分隔線 | 3px | — | — |

## 3. 元件

### 3.1 訊息泡泡

- **別人的訊息**：靠左，底色 `--surface`，上方是代號，時間在泡泡**右邊**、跟底部對齊。
- **自己的訊息**：靠右，底色 `--own`，時間在泡泡**左邊**。
- 泡泡最大寬度：手機 250px、電腦 520px。內距 9px 13px。
- **連續訊息**：同一個人 1 分鐘內的訊息，只有第一則顯示代號。訊息之間距 4px，不同人的訊息群組之間距 10～12px。
- **有圖片**：泡泡內距改成 6px，圖片有 2px 黑框、12px 圓角，文字在圖片下方，左右多內縮 7px。圖片寬約 204～220px（手機）。
- **送出中**：整則訊息透明度 0.55，時間的位置改成顯示「送出中…」。有圖片時，縮圖底部有進度條（白底、黑框、膠囊形，填滿的部分用 `--pink`）。
- **傳送失敗**：泡泡框線改成**虛線**、沒有影子。泡泡左邊依序是橘色膠囊「⚠ 傳送失敗」、「重試」、「刪除」（白底小按鈕，高 32px）。

### 3.2 引用區（在回覆的泡泡裡面）

- 在泡泡內、文字上方：底色 `--quote`，2px 黑框，12px 圓角。
- 左邊是 4px 寬的粉紅色條，右邊上下兩行：代號（12px / 700）、原訊息前段（13px、`--muted`）。原訊息是圖片時，顯示「[圖片] 文字」。
- **此訊息已收回**：只有一行斜體灰字，外觀一樣（還是可以點）。
- **原訊息已無法顯示**：**虛線框**、斜體灰字，**沒有**點擊效果，看起來不像按鈕。

### 3.3 表情標籤

- 在泡泡下方，高 30px，膠囊形，2px 框，文字是「👍 3」。
- 別人按的：`--surface` 底色、沒有影子。
- **自己有按的**：`--yellow` 底色，加上 `2px 2px 0` 影子。
- **誰按了**：黑底白字的小提示框，出現在標籤上方，文字是「👍 小貓、阿土、Momo」。

### 3.4 系統訊息

- **日期分隔線**：置中的黑底白字膠囊，「今天」或「10 月 12 日」。
- **進出提示、已收回**：置中的 13px 灰字，沒有底色，例如「阿土 進入了聊天室」「阿土 收回了一則訊息」。

### 3.5 電腦版：滑鼠移到訊息上

- 在泡泡旁邊（自己的訊息在左側、別人的在右側）出現白底小工具列：2.5px 框、12px 圓角、`2px 2px 0` 影子。裡面是 36px 的圖示按鈕：回覆、表情，自己 2 分鐘內的訊息還有收回。
- 按下表情後，表情按鈕變黃，工具列上方跳出**表情選擇小框**：黃底、3px 框、16px 圓角、`4px 4px 0` 影子，6 個 44px 的按鈕排成一排。自己按過的表情有白底黑框。

### 3.6 手機版：長按選單

- 整個畫面蓋上 `rgba(17,17,17,0.6)` 的遮罩。被長按的訊息浮在遮罩上方，放大到 1.04 倍，影子加大成 `4px 4px 0`。
- 選單在訊息下方，寬 300px，白底大卡片：
  - 最上面是黃底的一排 6 個表情（44px 高），下面接一條 3px 框線。
  - 「回覆」「收回」兩列，每列高 56px，左邊是圖示，文字 17px / 700，兩列中間隔一條 2px 線。
  - **收回**那列的右邊，用灰字顯示「還剩 1:24」（見第 5 節）。

### 3.7 輸入區

- 白底，上方有 3px 分隔線。
- **回覆列**（回覆時才出現）：在輸入列上方，下緣是 **2px 虛線**。依序是回覆圖示、「**回覆 阿土：**可以傳原圖給我嗎」（太長就截斷並加「…」）、✕ 按鈕。
- **圖片預覽**（選了圖片才出現）：`--quote` 底色的小卡片，裡面是縮圖（56×44）、檔名、✕ 按鈕。
- **輸入列**：📎 按鈕（48px，電腦 52px）＋ 輸入框（圓角 14px、`--input` 底色）＋ 送出按鈕。
  - 手機的送出鍵是 48px 的正方形圖示按鈕；電腦是「圖示＋送出」文字按鈕，粉紅底。
  - 送出鍵不能按時（沒內容、超過字數、斷線），底色改成 `--disabled`，而且沒有影子。
- **電腦版說明列**：輸入列下方 12px 灰字「Enter 送出・Shift+Enter 換行・可以直接貼上或拖曳圖片」（見第 5 節）。
- **剩餘字數**：剩不到 50 字時，才在輸入框右邊用 Space Mono 顯示「剩 12 字」。超過 500 字時，輸入框底色變成 `#FFE3D9`，並出現橘色膠囊「超過 3 字」，送出鍵變灰。
- **錯誤提示**：橘底、2px 框、10px 圓角，前面有 ⚠ 圖示，例如「只能傳 jpg、png、gif、webp 圖片」「GIF 最大 3MB」。

### 3.8 浮動和提示類

| 元件 | 樣子 |
|---|---|
| 「↓ N 則新訊息」 | 在訊息列表底部置中，粉紅色膠囊，高 40px，`3px 3px 0` 影子 |
| 連線中斷橫幅 | 緊貼在頂端列下方、橫跨整個寬度：黃底、下緣 3px 框，左邊是斷線圖示，文字「連線中斷，正在重新連線…」（14px / 700） |
| 展示模式提示條 | 畫面最上方：黑底白字、13px / 700、置中 |
| 短暫提示 | 黑底白字、12px 圓角、粉紅色實心影子 `4px 4px 0`，出現在輸入區上方，幾秒後消失 |
| 拖曳圖片時的遮罩 | 蓋住聊天室：90% 不透明的黃色、3px 黑色虛線框，中間是圖片圖示和「放開以加入圖片」（20px / 900） |

## 4. 各畫面版面

### 4.1 進入畫面
- 最上方是展示模式提示條（只在階段一）。
- 提示條以下的內容區塊背景是**淺藍色 `#CDE8FF`**（只有進入畫面這樣，聊天室仍用 `--bg`）。
- 背景有三個裝飾色塊，不能點，螢幕報讀器也不會讀到：右上一個粉紅圓形、一個稍微旋轉的黃色方塊，左下一個薄荷綠圓角方塊。
- 內容垂直置中，依序是：
  - 薄荷綠膠囊「不用註冊・不用登入」
  - 大標題「匿名／聊天室」（分兩行）
  - 一行說明「取一個代號，直接開聊。」
  - 白色卡片：「你的代號」標籤、56px 高的輸入框、左邊「1～12 個字」右邊「2/12」、錯誤提示、56px 高的粉紅色「進入聊天室」按鈕

### 4.2 聊天室：手機（寬 390px）
- 頂端列高 64px，依序是：標題、薄荷綠的人數膠囊（人數圖示＋數字）、「離開」按鈕。
- 展開名單時，人數膠囊變成**黑底、薄荷綠字**。名單是白色大卡片，從頂端列下方展開，標題列是薄荷綠底；名單下方的聊天室蓋上 45% 的黑色遮罩。
- 訊息列表的內容貼著底部排列，往上長。
- **空聊天室**：中間是一個稍微旋轉的黃色方塊，裡面有對話框圖示，下方是「還沒有人說話，打個招呼吧」（20px / 900）。

### 4.3 聊天室：電腦
- 由上到下：展示模式提示條 → 頂端列（高 72px，左邊有一個稍微旋轉的粉紅色方塊當標誌）→ 主體。
- 主體左右兩欄：訊息區（左右內距 32px）和右側線上名單。
  - 線上名單寬約 240px，左緣有 3px 框線，標題列是薄荷綠底。
  - 視窗變窄時，名單會換行到下方。
- 頂端列的人數膠囊只顯示人數，不能點。

### 4.4 圖片全螢幕檢視
- 背景是 94% 不透明的黑色。
- 圖片置中，最大寬度 960px，外面有 4px 白框，右下角有粉紅色實心影子 `10px 10px 0`。
- 右上角是黃底的關閉按鈕（52px）；圖片下方是灰字「點一下任何地方，或按 Esc 關閉」。

### 4.5 測試面板（`?debug=1`）
- 3px 黑框的卡片。最上面是黑底、薄荷綠等寬字的「目前使用：本機版」。
- 下面三列開關：「模擬斷線」「下一則訊息送失敗」「上傳變慢」，每列高 52px。

## 5. 設計時新增、畫面清單沒寫的東西

以下三項是 `/design` 時加上的，還沒寫進 `architecture.md`。做前端時照做；不要的話，從這裡刪掉即可。

1. **長按選單的「收回」旁邊顯示剩餘時間**：例如「還剩 1:24」，讓使用者知道還能收回多久。
2. **電腦版輸入框下方的說明列**：「Enter 送出・Shift+Enter 換行・可以直接貼上或拖曳圖片」。
3. **「原訊息已無法顯示」用虛線框**：它點了沒反應，用虛線框比較不會被誤認成按鈕。

## 6. 無障礙

- 所有能點的東西都用真正的 `<button>`、`<a>`、`<input>`，不用 `<div>` 加點擊事件。
- 只有圖示的按鈕都要加 `aria-label`，例如「附加圖片」「取消回覆」「關閉」「送出」。
- 表情標籤的 `aria-label` 要寫出人數，例如「❤️ 1 人，包含你」；自己按過的加上 `aria-pressed="true"`。
- 錯誤提示用 `role="alert"`；連線橫幅和短暫提示用 `role="status"`。
- 裝飾用的色塊和圖示加上 `aria-hidden="true"`。
- 文字和背景的對比度至少 4.5:1。灰字一律用 `--muted`，不要再調淡。
